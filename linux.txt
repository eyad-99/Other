-  🔑 Absolute Path (starts with /)
Absolute path means the path is specified from the root directory /.
Example:
cd /usr/local/bin
→ This takes you directly to /usr/local/bin, no matter where you currently are.
🔑 Relative Path (without /)
Relative path means the path is specified relative to your current working directory.
Example:
cd Documents
→ If you’re in /home/eyad, this moves you to /home/eyad/Documents.

-ls /usr
You’re listing the contents of the /usr directory, which is part of the Linux filesystem hierarchy. The leading / means it’s an absolute path, starting from the root directory.

-ls ~ /usr
you’re asking Linux to list the contents of two directories at once:
~ → expands to your home directory (e.g., /home/eyad).
/usr → the absolute path to the /usr directory.
So the command will output two separate listings:
The files and folders inside your home directory.
The files and folders inside /usr.

-cat  
In Linux, cat is a command used to read, concatenate, and display file contents. It’s short for concatenate.

🔑 Main Uses of cat
View file contents

bash
cat file.txt
→ Prints the contents of file.txt to the terminal.

Concatenate multiple files

bash
cat file1.txt file2.txt > combined.txt
→ Joins file1.txt and file2.txt into a new file combined.txt.

Create a new file

bash
cat > newfile.txt
→ Lets you type text directly into newfile.txt (press CTRL+D to save and exit).

Append to a file

bash
cat >> existing.txt
→ Adds new content to the end of existing.txt.
🔑 Redirection Operators
< → Input redirection

Feeds a file into a command as stdin.

Example:

bash
cat < file.txt
→ Reads file.txt and prints its contents (same as cat file.txt).

> → Output redirection (overwrite)

Sends command output to a file, replacing its contents.

Example:

bash
cat file.txt > newfile.txt
→ Copies contents of file.txt into newfile.txt, overwriting if it exists.

>> → Output redirection (append)

Sends command output to a file, adding to the end instead of overwriting.

Example:

bash
cat file.txt >> existing.txt
→ Appends contents of file.txt to existing.txt.






-pipeline
How Pipelines Work
Pipe operator → |

Takes the output of the command on the left and feeds it as input to the command on the right.

📘 Examples
Simple pipeline:

bash
ls -l | less
→ Shows the long listing of files, but scrollable with less.

Filter with grep:

bash
ps aux | grep firefox
→ Lists running processes, then filters only those containing “firefox”.

Count lines:

bash
cat file.txt | wc -l
→ Counts the number of lines in file.txt.

Chain multiple commands:

bash
dmesg | grep error | wc -l
→ Finds kernel log entries containing “error” and counts them.

⚖️ Why Pipelines Are Useful
Combine simple commands into complex workflows.

Avoid creating temporary files.

Efficient for text processing and system monitoring.
