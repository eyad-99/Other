2- replica set
A ReplicaSet in Kubernetes ensures that a specified number of identical Pod replicas are running at all times.
For example, if you want 3 copies of your .NET API running, a ReplicaSet maintains 3 Pods.
Think of it this way: Labels tell the ReplicaSet which Pods to count; replicas: 3 tells it how many Pods to maintain.

5-In Kubernetes, a Volume lets a container access storage outside its own container filesystem. It's especially important when running databases because containers and Pods can be replaced.


Term	                                                          Meaning

PersistentVolumeClaim (PVC)	                                  A request for storage by an application.
StorageClass	                                                 Defines how Kubernetes can provision storage dynamically.

YAML property	Value	Meaning
containerPort	8080	Documents the port your application is expected to listen on inside the container. It does not configure the app's listener by itself.
targetPort	8080	The destination port on the selected pod to which the Service forwards traffic.
port	80	The port exposed by the Service inside the Kubernetes cluster.
nodePort	30080	The port exposed on each node's network interface, subject to the cluster's networking configuration.
Notice that containerPort and targetPort are both 8080, but they have different jobs:
- containerPort describes the container's expected port.
- targetPort tells the Service where to send traffic.
