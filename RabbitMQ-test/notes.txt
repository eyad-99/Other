10- channel.BasicQos(prefetchSize: 0, prefetchCount: 1, global: false);
🔍 What it means (simple)

👉 “Give me only 1 message at a time, and don’t send another until I ACK it.”

🔹 Parameters explained
1) prefetchSize: 0
Limit based on message size (bytes)
0 = ignore size limit
👉 Almost always left as 0
2) prefetchCount: 1
Max number of unacknowledged messages allowed per consumer

👉 1 means:

Consumer gets one message
Must ACK it before receiving the next
3) global: false
false → applies per consumer
true → applies to the whole channel

👉 Usually: false
